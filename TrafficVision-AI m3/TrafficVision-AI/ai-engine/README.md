# TrafficVision AI

Traffic analysis and feature engineering workspace.

## Layout

- `notebooks/`: exploratory analysis notebooks
- `data/`: local datasets and data notes
- `src/`: reusable Python feature engineering code

## Setup

```bash
cd ai-engine
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Open `notebooks/traffic_eda.ipynb` to begin the exploratory analysis.
