## Severity Guide

- Critical: production outage, data loss, user safety risk
- High: release blocking, major user impact
- Medium: degraded functionality but workaround exists
- Low: cosmetic or minor usability issue

## SLA

- Critical: same day
- High: within 24 hours
- Medium: within 3 days
- Low: within 1 week
