## Defect Workflow
Whenever a problem is found:
1. Create a GitHub Issue.
2. Add the appropriate label(s).
3. Assign the Issue to the responsible team member.
4. Add the Issue to the Milestone 1 project.
5. Move the Issue through:
   Todo → In Progress → Testing → Done

## Example Defect

### Issue Title
